# ue-RewindDebugger

A lightweight and highly extensible runtime playback debugger.

Similar to Unreal Engine’s Rewind Debugger, it can record complete gameplay sessions and provide frame-by-frame playback with detailed state inspection, making issue analysis, diagnosis, and debugging more intuitive and efficient.

Future Plan: Support recording debugging data in packaged builds and loading it for inspection in the Unreal Editor.

一款轻量级、易于扩展的运行时回放调试器。

功能类似于 UE 的 Rewind Debugger，可完整录制游戏运行过程，并支持逐帧回放与详细状态查看，让问题分析、定位和调试更加直观高效。

未来计划：支持在打包后的游戏中录制调试数据，并在 Unreal Editor 中加载和查看。
